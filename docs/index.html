LnkShortcutTool

Version 1.0 | Security Research Tool for creating LNK shortcuts

Author: Security Research Team

About This Project

LnkShortcutTool is a professional tool for creating Windows LNK shortcuts for security testing and penetration testing purposes. This project provides both a command-line interface (CLI) and a graphical user interface (GUI) for creating shortcuts pointing to SMB servers.

Features

  • Create Windows .lnk shortcuts easily.
  • Supports specifying SMB server IP, shared folder, and target file.
  • Customizable icon for the shortcut.
  • Graphical User Interface (GUI) for ease of use.
  • Command-Line Interface (CLI) for automation.

Usage

GUI Mode

Simply run the program without arguments:

python main.py

CLI Mode

Run with arguments:

python main.py -path "C:\path\to\save" -ip "192.168.1.100" -share "SharedFolder" -file "example.exe" -icon "icon.ico"

Installation

Install required dependencies via pip:

pip install pywin32

Then run the program:

python main.py
