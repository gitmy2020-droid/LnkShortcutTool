**Version:** 1.0  
**Author:** Security Research Team  
**License:** MIT License  

---

### 📄 Description
LNK Shortcut Creator is a penetration testing tool designed to create Windows `.lnk` shortcuts pointing to remote SMB servers.  
It can be run either via GUI or Command-Line Interface (CLI) and is intended for **educational and security testing purposes only**.

---

### 🛠 Features
- Create `.lnk` shortcut files pointing to remote SMB paths.
- Optional custom icon for shortcuts.
- GUI and CLI support.
- Simple and clean interface for usability.
- Written in Python with `tkinter` and `pywin32`.
